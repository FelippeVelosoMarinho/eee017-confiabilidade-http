# Reliability-App (UFMG EEE017)

Índices de confiabilidade sobre métricas HTTP no formato do OpenTelemetry: R por requisição, disponibilidade em relação ao SLO, MTBF e MTTR, calculados por janela de tempo. Metas, limite de lentidão (τ), janela e volume mínimo são configuráveis por variáveis do dashboard.
